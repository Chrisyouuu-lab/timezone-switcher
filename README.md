# 时区切换（macOS）

一个很小的 macOS 原生小工具，用来在「美国洛杉矶」和「中国北京」之间一键切换系统时区。

窗口里同时显示两地的当前时间和 UTC 偏移，点一下就切换，不用再进「系统设置」里翻城市列表。

## 功能

- 同时显示洛杉矶（`America/Los_Angeles`）和北京（`Asia/Shanghai`）的当前时间
- 一键切换系统时区，切换前自动关闭「根据当前位置自动设置时区」
- 提权走系统原生的密码 / Touch ID 弹窗，不保存任何密码
- 纯本地运行：不发网络请求、不写开机自启、不改动时区以外的任何设置

## 系统要求

- macOS 13 或更新版本
- Apple Silicon 或 Intel 芯片
- 当前登录的是管理员账户（改时区需要提权）

## 安装

### 方式一：直接使用打包好的 App

把 `时区切换.app` 拖进「应用程序」文件夹即可。

这个 App 使用 ad-hoc 签名、没有经过 Apple 公证，第一次打开会被 Gatekeeper 拦截。任选一种方式放行：

**系统设置**：双击打开 → 点「完成」→ 系统设置 → 隐私与安全性 → 安全性 → 「仍要打开」→ 验证密码 → 再点一次「仍要打开」。

**终端**：

```bash
xattr -dr com.apple.quarantine /Applications/时区切换.app
```

### 方式二：从源码编译

需要 Apple 命令行开发工具：

```bash
xcode-select --install
```

然后在本目录下执行：

```bash
bash build.command
```

编译产物会安装到 `~/Applications/时区切换.app`。自己编译的 App 不会触发 Gatekeeper 拦截。

## 使用

1. 打开 App，窗口顶部显示当前系统时区，两张卡片分别显示洛杉矶和北京的时间
2. 点「切换到洛杉矶」或「切换回北京」
3. 输入开机密码或验证指纹，时区立即生效

切换失败时窗口里会显示红色的错误信息，错误文本可以选中复制。

## 它改动了什么

| 项目 | 说明 |
|---|---|
| 系统时区 | 改成你选的城市，用 `systemsetup -settimezone`；若该命令未生效则直接更新 `/etc/localtime` 软链并发出 `com.apple.system.timezone` 通知 |
| 自动设置时区 | 第一次切换时被关闭（`/Library/Preferences/com.apple.timezone.auto`），否则系统会按定位把时区改回去 |
| 其他 | 无。不修改时间本身，「自动设定时间与日期」（网络授时）保持原状 |

切回北京时**不会**自动重新打开「自动设置时区」，需要的话去「系统设置 → 通用 → 日期与时间」手动打开。

## 卸载

先把时区切回你需要的城市，退出 App，然后：

```bash
rm -rf /Applications/时区切换.app
```

卸载不会恢复「自动设置时区」的开关状态。

## 源码结构

| 文件 | 说明 |
|---|---|
| `main.swift` | 主程序（SwiftUI 界面 + 时区切换逻辑） |
| `icon.swift` | 生成 App 图标的脚本 |
| `Info.plist` | App 元信息 |
| `build.command` | 编译并安装到 `~/Applications` 的脚本 |

## 说明

这个工具只做一件事：改系统时区。没有任何绕过检测、伪造指纹之类的逻辑——浏览器看到的时区就是系统时区，改完之后浏览器自然跟着变。
